Live demo — your key, your provider, your browser

This page has no backend. Your key is stored only in this browser's localStorage and requests go straight from your browser to the provider you pick. Nothing is proxied through any server of ours, because there is no server of ours. It is your own quota being spent.

The key never leaves your browser except in the request to the provider itself. Stored in localStorage only. Use the “Forget my key” button below when you are done.

Browser-to-provider calls need the provider to allow cross-origin requests. Anthropic, OpenAI, Groq and OpenRouter all do. A local server such as Ollama must be started with permissive origins (OLLAMA_ORIGINS=*) before a web page can reach it.

What makes it different

Bring your own model

No provider is hardcoded. Set an API key and that provider appears. Set several and switch between them at runtime. The model list is discovered from whichever provider you configured, so it never goes stale.

Runs anywhere

A real docker compose up path with PostgreSQL included. No platform service is mandatory — Vercel Blob, bot detection and OpenTelemetry are all optional and off by default.

Your data stays yours

Local Postgres, no telemetry by default, and no third-party requests from the browser at runtime. Provider logos and avatars are rendered locally rather than fetched from someone else's CDN.

Genuinely offline capable

Point it at Ollama, llama.cpp, vLLM or LM Studio through any OpenAI-compatible endpoint. No API key, no outbound request, no account.

Quick start

git clone https://github.com/iampopye/chatbot.git
cd chatbot
cp .env.example .env

# generate a session secret and put it in .env as AUTH_SECRET
openssl rand -base64 32

# add a provider key to .env, for example
#   ANTHROPIC_API_KEY=...
# or point at a local model server
#   OPENAI_COMPATIBLE_BASE_URL=http://host.docker.internal:11434/v1
#   OPENAI_COMPATIBLE_MODELS=llama3.1:8b

docker compose up -d

The app is then on http://localhost:3000. Postgres runs in the stack and migrations are applied on start.
